# 图像聚类实验代码说明

## 任务要求

根据作业要求，实现图像聚类任务，包括：
- **1.0**: 问题的形式化描述 (5%)
- **1.1**: 如何处理图像特征 (5%)
- **1.2**: 选择合适的聚类算法 (10%)

## 数据集

- 位置：`DM_2025_Dataset/Cluster/dataset/`
- 数量：600张图像
- 类别：6类（cable, tile, bottle, pill, leather, transistor）
- 每类：100张图像

## 代码结构

### 1. 问题形式化描述 (1.0)

代码中包含了问题的形式化描述，说明了：
- 输入：600张图像
- 目标：将图像聚类到6个类别
- 方法：特征提取 + 聚类算法

### 2. 图像特征提取 (1.1)

实现了三种特征提取方法：

1. **ResNet50特征**（推荐）
   - 使用预训练的ResNet50模型
   - 提取2048维特征向量
   - 适合捕获图像的深层语义特征

2. **VGG16特征**
   - 使用预训练的VGG16模型
   - 提取特征图
   - 计算量较大

3. **颜色直方图特征**
   - 传统方法，不依赖深度学习
   - 提取96维特征（RGB各32维）
   - 计算快速，但表达能力有限

### 3. 聚类算法 (1.2)

实现了三种聚类算法：

1. **K-means**
   - 最常用的聚类算法
   - 需要预先指定簇数
   - 适合球形簇

2. **DBSCAN**
   - 基于密度的聚类
   - 可以自动发现簇数
   - 能处理任意形状的簇

3. **层次聚类 (Agglomerative)**
   - 自底向上合并
   - 需要预先指定簇数
   - 可以生成树状图

### 4. 评估指标 (1.3)

使用以下指标评估聚类效果：

1. **调整兰德指数 (ARI)**
   - 范围：[-1, 1]
   - 值越大越好
   - 考虑随机分配的情况

2. **标准化互信息 (NMI)**
   - 范围：[0, 1]
   - 值越大越好
   - 衡量两个标签分布的一致性

3. **轮廓系数 (Silhouette Score)**
   - 范围：[-1, 1]
   - 值越大越好
   - 衡量簇内紧密度和簇间分离度

## 输出结果

运行后会生成：

1. **控制台输出**

## 实验建议

### 特征提取方法选择

- **有GPU且追求高精度**：使用 `resnet` 或 `vgg`
- **无GPU或快速实验**：使用 `histogram`

### 聚类算法选择

- **已知簇数**：使用 `kmeans` 或 `agglomerative`
- **未知簇数**：使用 `dbscan`（但需要调参）

### 参数调优

- **K-means**: 可以尝试不同的 `random_state` 和 `n_init`
- **DBSCAN**: 调整 `eps` 和 `min_samples` 参数
- **特征维度**: 如果特征维度太高，可以考虑使用PCA降维

## 注意事项

1. 首次运行时会下载预训练模型（如果使用CNN特征）
2. 使用CNN特征需要GPU或足够的CPU内存
3. 可视化需要图形界面支持
4. 确保数据集路径正确
